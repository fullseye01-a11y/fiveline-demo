## 不可遺漏的整合模組

1. **身份與租戶隔離**：管理者／顧問／客戶登入，後端 access control + PostgreSQL RLS、客戶資料分區、稽核日誌、權限/越權 E2E 測試。不得只做前端遮蔽。
2. **全球標的資料中心**：境內外共同基金的所有 share class、境內上市/上櫃股票 ETF、美股與全球 ETF；NAV、配息、匯率、官方日 OHLCV、分割/除權息/total return 個別保存；清單去重、來源合法性與時間戳；不能只收四五星基金。
3. **五線譜與回測引擎**：+2/+1/中軸/-1/-2 SD、Z-score、六策略比較、DCA/加碼、停利、CAGR/XIRR/Sharpe/MDD/Calmar、Rolling 1/3 年、恢復天數、投入資金使用率、含息績效；與原 Excel 固定樣本逐欄對帳。
4. **RR1–RR5 風險**：客戶風險承受/需求問卷與商品風險分級分開；先選 RR 範圍再評分；未選不強制排名。容忍 MDD、流動性、持有年期、波動、集中度、幣別及相關性與壓力情境。
5. **智能資產配置**：全平台的持倉回查 NAV/配息資料庫；舊持倉 B/D/F 輸入保護、舊 E 現有占比系統計算；「漸進調整」新資金優先補低配、另一組「立即最佳化」估買賣差額；股債/區域/全球/台灣/科技比例與已揭露持股重疊，保守/基準/樂觀分析與多資產回測。
6. **退休財富規劃**：初始資金、年齡/年期、投入與提領、配息再投入、目標達成率、通膨、費稅、月度現金流、不同情境、下行風險警告，不提供保證收益。
7. **客戶投資顧問入口**：自選、保存配置、客戶持倉健檢、雙層次白話＋專業建議、PDF 報告、更新狀態、操作記錄、快速/完整更新、資料品質。
8. **iPhone 與正式運營**：RWD、一般/專業模式、登入隔離、資料庫備份/還原、失敗監控、回滾、個資權限、來源授權與 UAT。

## 發布判準

* 全部 27 張表的功能依賴有明確新模組歸屬（維護/內部資料工作表不必一張對應一個公開頁面；是否重複先查公式與 VBA，不憑名稱刪）。
* 授權測試證明客戶不可讀寫別人的資產、問卷、配置及報告。
* Excel 舊系統和網頁引擎對照：五線譜、回測、配置及退休的固定樣本數值/差異有測試報告。
* 全市場覆蓋進度和 NAV/配息/官方 OHLCV 的資料日期及缺口可見，不可將尚未收錄部分稱為「已匯入」。
* 實際異地備份及還原演練、可回滾部署，正式上線前資料授權／商用條款通過核對。
* 免費方案的儲存/流量/休眠額度不足時先告知，不默默轉付費，不犧牲安全。
