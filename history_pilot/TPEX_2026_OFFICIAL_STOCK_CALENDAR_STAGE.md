# TPEx 115 年度官方開休市表｜獨立上櫃股票試跑（2026-10-18）

## 本階段限制與安全性

- 正式來源：櫃買中心官方 [115 年有價證券櫃檯買賣市場開（休）市日期表](https://www.tpex.org.tw/storage/eb_data/11411/114007545811-1.pdf)，以及 [官方網頁](https://www.tpex.org.tw/zh-tw/announce/market/holiday.html)。
- 以 *官方 PDF* 一次性讀取+SHA-256 指紋為來源。使用 `pypdf` 擷取文字，核對年度、股票市場（不是債券）的春節前最後交易日、特殊假日與日期配對；官方網站若擋下載、PDF 格式/欄位/名稱變更、提取失敗就停止，**不得退回第三方假期推測當驗收**。
- 上櫃股票試驗標的 **6488、8069**，Neon 只查 market/code/day（不讀開高低收、不新增資料）。目前研究資料最後交易日 2026-10-13。
- *已驗證研究窗口*：2026-10-06 至 2026-10-13，照 115 年股市年度公告推算預定開市 5 天（10/09 國慶休市）。逐檔比較缺少預定日期與「休市卻有行情」。
- *擴大日期候選窗口*：2026-10-01 至 2026-10-13，照已公布年度股市休市表推算 8 天。10/01、10/02、10/05 只有「待確認是否應回補」的候選身分，**尚未核對當天股票上市/掛牌、個別停復牌及特殊臨時停市**，也沒有抓新價格。
- 115 年度公告可能區分股票、國際債券、債券處所議價等不同市場，絕不把債券結算交易日當作股票交易日。
- 公開健康端點仍只能回應 `/health`，正式五線譜、SD、六策略、原 Excel、基金及客戶資料均不受影響。
- 無完整個別公司行動與資料再分發授權前，不可宣稱整個市場已回補，也不准轉換含息長期報酬。

## 受控執行

1. 備份分支：`backup/history-pilot-before-tpex-calendar-20261018`。
2. 保持 `PILOT_FETCH_ON_BOOT`、`PILOT_BACKFILL_ON_BOOT`、`PILOT_COVERAGE_AUDIT_ON_BOOT`、`PILOT_TWSE_CALENDAR_PROBE_ON_BOOT` 全部為 `0`。
3. 唯獨測試部署時開 `PILOT_TPEX_CALENDAR_PROBE_ON_BOOT=1`。程式每次啟動只提出 **1** 個官方 PDF 請求，與所有行情匯入工作互斥；同步用的 Neon 是唯讀交易。
4. 在 Render build 驗證 Python 測試（原本 69 + 14 項 TPEx 新案例 = 83）。在 app logs 找 `HISTORY_TPEX_OFFICIAL_STOCK_CALENDAR` 或 `HISTORY_TPEX_CALENDAR_FAILED`。
5. 再將試跑開關改回 `0`，確認安全部署 live、日誌 `HISTORY_IMPORTS_DISABLED`；入庫前後筆數不變。

若正式 PDF 只因外站存取限制而無法取得，應保留 **沒有驗收完成** 的狀態；能從公開搜尋取得 PDF 名稱/摘要，不能取代在 Render 中成功擷取與比對的證據。直到排除來源問題前，缺漏清單不得當作確定能回補的正式交易日。
