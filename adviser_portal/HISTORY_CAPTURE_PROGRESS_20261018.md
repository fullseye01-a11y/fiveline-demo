# 歷史原始資料首次採集與幣別辨識修正（2026-10-18）

## 實際取得資料

新增通用 `sitca_history_capture.py`，利用公會公開的日期查詢表單，一次取得所有公司資料，不為個別基金編寫例外流程。入口為 `https://www.sitca.org.tw/ROC/Industry/IN2106.aspx?pid=IN2213_02`，由公會「境內基金各項資料／明細資料／基金淨值(日)」連結取得。

已保存四個原始 HTML 回應，以及隔離 SQLite 的 **16,438 筆未核准數值觀測**：

| 查詢與回應表單日期 | 數值觀測 |
|---|---:|
| 2023-10-18 | 3,937 |
| 2024-10-18 | 4,064 |
| 2025-10-17 | 4,145 |
| 2026-10-15 | 4,292 |
| 合計 | 16,438 |

每份原始檔與解析後表格分別計算 SHA256，四份表格指紋均不同。2026-10-16 查詢未達全量最低門檻，拒絕存入數值表；未把部分來源當作完整市場。來源內非數值、零值、負值及註記各自列為不可用，沒有補零或推估 NAV。部分舊級別沒有受益憑證代號，保留空值並計數，不自行補碼。

**日期綁定仍只有送出查詢條件與回應表單日期一致**，表格沒有逐列獨立日期欄位。四個日期樣本不代表連續三年，不證明每基金估值日完整、級別 ISIN 已核准或商用再散布授權。所有 SQLite 資料固定標為 `UNAPPROVED_SOURCE_OBSERVATION`，不串正式配置、六策略或客戶資料。正式三年完整基金核准仍為 0 檔。

原始檔、研究 SQLite、來源報告及 TDCC 近期原始資料已封存為私有研究備份，不提交公開 GitHub。公開 repo 只有程式與去價格的統計紀錄。

## 可續跑的受限採集指令

```bash
python -m adviser_portal.sitca_history_capture --dates 2023-10-18 2024-10-18 2025-10-17 2026-10-15 --root /private/sitca-research
```

一次只接受 1–31 個不重複且不在未來的明確日期，不推估基金估值日，不建立自動排程。既有檔案先重驗再重用，不重新下載；相同原檔再次執行不增加 SQL 重複列。每日期完成後提交隔離交易，即使後一日期失敗，前面原始檔與資料仍可重新驗證。跨日期回傳完全相同表格會被拒絕，避免只改表單日期卻接受同一份來源。原始 HTML 與 SQLite 均應存放在 repo 之外。

## 境外待查原因與實際修正

原來 `_ccy` 未完整支援 `紐西蘭幣→NZD`、`新加坡幣／星幣→SGD`、`瑞典幣／瑞典克朗→SEK`。新增這些明確幣別別名，仍要求相同代碼、合法 ISIN、完整級別名稱、同幣別與唯一官方基本資料；沒有放寬到只依基金名稱或 ISIN 合併。

同一份 2026-10-18 來源原檔重跑後，近期驗證由 **4,991 增至 5,032 級別**（增加 41），有效日期觀測由 **18,765 增至 18,922**（增加 157）。剩餘境外共 263 筆：

|---|---:|
| 最近來源存在該級別，但觀測值／日期無法通過數值日期檢查 | 187 |
| 最近來源沒有該 ISIN | 43 |
| 有 ISIN，但完整代碼／名稱／幣別組合不符 | 3 |

此分類僅說明現有 CSV 的可用性，不推斷停牌、清算、未成立或保證有歷史資料。掃描器輸出每級別 blocker_code，方便後續按類別處理。
