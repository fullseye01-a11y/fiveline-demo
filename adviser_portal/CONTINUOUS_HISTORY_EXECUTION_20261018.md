## 執行及續跑

```bash
python -m adviser_portal.continuous_history_import --start 2023-10-18 --end 2026-10-15 --fetch-workers 8 --root /private/research-history
```

- 取得日曆日期的全公司公開表格；不是為單檔基金寫專用流程。
- 最多 8 個來源請求在途，新請求至少相隔 1 秒；資料庫寫入與每日期狀態提交仍依日期串行。
- 來源為公會公開日期查詢 `https://www.sitca.org.tw/ROC/Industry/IN2106.aspx?pid=IN2213_02`。每個日期都保留原始回應，成功原檔改存 gzip；檔案 SHA 仍以原始未壓縮位元組計算。
- 成功日期不重抓、不重複寫入；來源待查和傳輸失敗保留原因，只有明確 `--retry-failures` 才重試。
- 連續三次傳輸失敗、來源 401／403／429、操作人暫停或日期預算會停止；剩餘日期仍明列待處理。
- 根目錄建立 `pause-requested` 可於日期邊界停止；移除後同指令續跑。
- 暫時性 SQLite readonly／busy／locked 會用相同來源位元組重新開啟交易重試，最多 3 次，不重複消耗預抓結果。
- SQLite 連線每日期明確關閉並於記錄狀態前重開，避免檔案被替換後仍使用舊連線。新增「匯入後、記帳前資料庫檔案被替換」的真實回歸測試。

## 壓縮來源管道

原始網頁約數 MB／日，gzip 後約數百 KB／日。在同一 Alpha 增加預設停用的管理者壓縮管道，固定只能取得上述官方來源及一個合法日期；不接受外部 URL、CSV 上傳、任意資料表或客戶紀錄。

- 需要 `ADVISER_RESEARCH_RELAY_TOKEN`，不設或短於 48 字元一律 403；比對採常數時間。
- 憑證不會提供給前端、不放 URL、原始檔、公開 repo 或研究備份。
- 最多 8 個獨立匿名官方來源 session 在途；沒有共用 CookieJar 的跨執行緒寫入。
- 採集端仍驗證 HTTPS 管道、回應大小及 gzip 展開上限，再走同一套原始表格驗證。
- 用 2023-10-19 真實原檔驗證壓縮來回，原始 SHA256 完全相同：`d7b1821e10737c5b693daa334099987365da0baa2185be6629fffe15a5521f8a`。
- 管道只供這次受控研究採集。它不是客戶登入服務，也不是公開歷史價格 API；任務後停用憑證。

## 境外官方三年歷史管道

`fundclear_history_import.py` 使用 FundClear 官方網站的公開三年歷史查詢，並以官方基本資料 CSV、61 個機構的級別選單、精確代碼、完整正規化名稱、ISIN 與幣別綁定級別。不是為特定基金商編寫流程。官方選單與網站既有 5,295 個境外級別均已對回，兩份名錄的原始 SHA256 都保存在研究資料內。

```bash
python -m adviser_portal.fundclear_history_import --root /private/offshore-history --selectors --catalog /private/catalog.json
python -m adviser_portal.fundclear_history_import --root /private/offshore-history --all-batches --workers 8
python -m adviser_portal.fundclear_history_import --root /private/offshore-history --audit --recent /private/tdcc-recent.csv
```

- 本次期間固定為 2023-10-18～2026-10-15，每批最多 100 個級別、最多 8 條連線，新請求至少相隔 0.5 秒。
- 可選 `--pooled` 使用已安裝的 aiohttp 重用匿名連線；不啟用時使用 Python 標準函式庫。
- 來源回傳每筆 NAV 日期與原始十進位字串；不採用比較圖的正規化報酬，不補值，不改算含息績效。
- 所有回應保留 gzip 原檔、請求內容及未壓縮 SHA256；SQLite 寫入序列化、可續跑，成功級別不重抓。
- 401／403／429、非預期轉址、HTML 回應或連續來源傳輸故障會停止；根目錄的 `pause-requested` 可在批次邊界暫停。
- 日期重複、越界、幣別不符與非正數 NAV 不入價格表；無法取得的級別保留待查，不從名錄刪除。
- 驗收重新比對原檔、請求級別、網站名錄與所有入庫數值，另輸出時間缺口待查清單，並與獨立近期官方 CSV 核對重疊日期。
- 缺少 ISIN／檢查碼不符及共用 ISIN 都保留身分限制；來源可公開查詢不等同商業使用權已核准。

價格均為 `UNAPPROVED_SOURCE_OBSERVATION`。回應級別依請求與官方選單綁定，沒有獨立的逐筆級別簽章；不推定基金成立日或完整估值日曆。


## 境內逐級別候選連結

`domestic_catalog_candidates.py` 僅處理已匯入來源原檔的一致性研究副本。原檔 SHA 必須存在於已匯入來源快照，查詢日期須與名錄版本相近。依官方 HTML 的明確換行區隔完整級別名稱與風險註記，再做完整正規化名稱與幣別的一對一候選對照；級別字樣、幣別不同或雙向重複都列為待查。

2026-10-14 官方表格共 4,473 個來源級別：4,471 個建立目前名錄候選，另 1 個缺受益憑證代號、1 個沒有目前名錄對應。全部 4,472 個網站境內名錄紀錄仍保留，包含 1 個尚無候選者。

歷史資料仍保留 6,003 個原始來源身分，其中 5,121 個可按精確受益憑證代號、基金統編與幣別產生目前級別候選。4,343 個目前級別可連結共 2,617,296 筆研究觀測，未發現候選級別同日期重複。其餘觀測保留未連結狀態，不按相似名稱合併。

這些只是候選連結：不改寫任何價格或原始來源身分，不核准歷史名稱連續性、基金成立日、估值日曆或商業使用權。現行 ISIN 名錄也只提供候選：323 個受益憑證代號與完整名稱一致、3,740 個代號一致但名稱連續性待查、408 個沒有唯一現行名錄候選。沒有以缺漏或不符為由刪除基金。
