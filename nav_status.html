這份報告可以與不能判斷的事情

可以：檢查每檔最後資料日期、現有 NAV 筆數及是否存在「配息日早於 NAV 起始日」的歷史覆蓋問題。

尚不能：確認交易日逐日無缺漏、驗證配息已正確還原、取得最新基金 NAV 或完成六策略正式回測。表格的「0 筆較早配息」不表示完整無缺。

後續開發：資料供應商授權 → 私有伺服器匯入暫存 → 逐筆驗證與人工審核 → 正式 NAV 更新 → Excel 公式逐筆對帳。公開 GitHub Pages 不儲存 API 金鑰或客戶持倉。
