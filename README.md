# 五線譜智能財富平台｜V2.6 公開展示版

本儲存庫包含靜態展示頁面：
- `index.html` — 首頁
- `five_line.html` — 五線譜分析（歷史資料快照，並非即時 NAV）
- `six_strategy.html` — 六策略研究展示（未與原 Excel 全部對帳）
- `nav_quality.html` — NAV 缺口品質檢查
- `distribution_audit.html` — 配息日期稽核

網站為**公開示範原型**，不包含登入服務或真實客戶資產資料；不得作為正式投資建議或最新行情。

## 部署 GitHub Pages

在儲存庫的 **Settings → Pages** 選擇 **Deploy from a branch**，再設 **main / (root)**，點 **Save**。完成部署後 GitHub 會顯示網站網址。

原始 Excel、資料庫、後端與個人客戶持倉不放入此公開儲存庫。
