# 五線譜｜官方公開 NAV 原始快照庫（未核准）

此分支專門保存政府開放資料中的基金公開淨值觀察，供日後資料品質研究及人工核對。**不保存投資客戶資料、持倉或登入資訊**。

- 原始資料：證券投資信託基金每日淨值 <https://data.gov.tw/dataset/11109> 與境外基金基金總覽—全球型 <https://data.gov.tw/dataset/37818>
- 授權：政府資料開放授權條款第 1 版 <https://data.gov.tw/license>
- 資料提供機關：金融監督管理委員會證期局／投信投顧公會／臺灣集中保管結算所
- JSON 路徑：`public_nav_history/YYYY/MM/YYYY-MM-DD_run-<GitHub Actions ID>.json`
- 每份檔案記載資料抓取時刻、官方來源、基金代碼、ISIN（來源有提供才保留）、幣別、**淨值有效日期**、原始淨值與 SHA-256 校驗。
- 同一基金同一天的 NAV 如有後續官方更正，新檔保留更正觀察，重建工具會**阻止直接覆寫**，等待人工比對。
- 目前只有經完整名稱及幣別篩選的基金候選（開始時為 39 檔），**不是已核准配對**。其他 29 檔未收錄不代表已退市或沒有 NAV。
- 本資料不能回填正式 Excel，也不是回溯到成立日的完整歷史 NAV，更不能將未經核對的配息／分割資料直接用作含息績效。
- SQLite 是使用 `python -m tools.rebuild_public_nav_sqlite` **臨時重建**的檢視檔；版本化 JSON 才是公開原始證據。
- Git 分支中的版本紀錄不受 GitHub Actions 30 天 artifact 期限直接限制，但仍受 GitHub 帳號、儲存庫管理與服務政策約束，不能取代異地備份或正式客戶私有資料庫。

請勿提交 API 金鑰、個資、帳號或客戶持倉。
